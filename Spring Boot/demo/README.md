# Ye jo Project hai vo basically demo hai yaani ki start.spring.io se liya gaya bina kisi modification ke

## Running Steps

Isko chalane ke liye simply ye follow karein


Ye wali command se sab kuchh existing compiled files clean ho jayengi samjhe
```
mvn clean
```


Ye wali file se mast jar file ban jayegi
```
mvn package
```


Jar file banne ke baad yaa to mvn ke tarike se chala lo yaa to jar file se chala lo

mvn wala tarika
```
mvn spring-boot:run
```

jar file wala tarika
```
java -jar target/demo-0.0.1-SNAPSHOT.jar
```
